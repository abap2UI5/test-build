## Install

1. The namespace `/ABAP2UI5/` has to exist in the system (SE03, changeable, with a developer license) and a package of that namespace to pull into.
2. abapGit: New Online, this repository, branch `rename_abap2ui5`, that package, Pull. The packages are named `<package>_01` (backend, with `_01_00` .. `_01_99`) and `<package>_02` (frontend, with `_02_01`, `_02_02`) - abapGit's PREFIX folder logic.
3. SICF: activate /sap/bc/abap2ui5/ui5, /sap/bc/ui5_ui5/abap2ui5/ui5, /sap/bc/bsp/abap2ui5/ui5, (and the namespace nodes /sap/bc/abap2ui5, /sap/bc/ui5_ui5/abap2ui5, /sap/bc/bsp/abap2ui5).
4. Open `/sap/bc/ui5_ui5/abap2ui5/ui5/index.html`.
